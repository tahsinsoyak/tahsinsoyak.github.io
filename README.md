## 🚀 Overview

This repository hosts the static build and assets for [tahsinsoyak.github.io](https://tahsinsoyak.github.io/), built with modern web technologies, responsive typography, and an emerald-accented design system.

### Highlighted Work & Projects
* **AjanBench-TR & Agriculture Benchmarks**: Policy-guided agentic evaluation frameworks and domain-specific LLM evaluation suites.
* **Cost Per Use & SmartDownload Chrome Extensions**: Production utility browser extensions.
* **Flatfoot Classifier**: Radiographic deep learning classification and Grad-CAM explainability pipeline.
* **Edge & Cloudflare Workers Applications**: Low-latency edge applications including the Strawberry landing showcase.

## 🛠 Tech Stack

* **Core**: Modern HTML5, Tailwind / Custom CSS Modules, Vite-bundled JavaScript
* **Typography**: Newsreader (Editorial Serif), Inter (Sans-serif), JetBrains Mono (Code)
* **Hosting**: GitHub Pages via automated deployment on the `main` branch
* **SEO & Social**: Full Open Graph (OG) metadata, Twitter cards, semantic metadata

## 💻 Local Development

To run or preview the portfolio locally:

```bash
# Clone the repository
git clone https://github.com/tahsinsoyak/tahsinsoyak.github.io.git
cd tahsinsoyak.github.io

# Serve with any static web server (e.g., Python or npx serve)
python -m http.server 8000
# or
npx serve .
```

Then visit `http://localhost:8000` in your browser.
